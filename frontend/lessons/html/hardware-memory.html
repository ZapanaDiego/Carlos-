🚚 Localidad Espacial: Cache Line (64 Bytes)

La CPU nunca trae un solo byte de la RAM; siempre carga un bloque continuo entero de 64 Bytes.

💻 Impacto Real en Código C++

✅ Recorrido por Filas (Fast) Cache-Friendly 
// Secuencial en memoria (Línea de caché optimizada)
for (int i = 0; i < 1000; ++i) {
    for (int j = 0; j < 1000; ++j) {
        suma += matriz[i][j]; // Acceso contiguo
    }
}
Resultado: ~99% Cache Hits
❌ Recorrido por Columnas (Slow) Cache-Unfriendly 
// Salta miles de bytes en memoria cada vez
for (int j = 0; j < 1000; ++j) {
    for (int i = 0; i < 1000; ++i) {
        suma += matriz[i][j]; // Salto continuo = Miss
    }
}
Resultado: Constantes Cache Misses (Thrashing)
